1. INTRODUCTION                                                         *neat*

neat.nvim bundles small replacements for noice.nvim (cmdline popup),
lualine.nvim (statusline), dressing.nvim (vim.ui.select) and snacks.nvim
(input, notifier, indent guides, LSP file rename). Every module is off until
its table sets `enabled = true`. Requires Neovim 0.12. The `cmdline` module
also needs nui.nvim. The snacks.nvim parts are copies that ship inside neat
(see NOTICE): snacks.nvim does not need to be installed.

==============================================================================
2. SETUP                                                          *neat-setup*

                                                                *neat.setup()*
neat.setup({opts})
    Configure neat.nvim and start the modules that set `enabled = true`.
    Options are checked with |vim.validate()|. >lua
        require('neat').setup({
          cmdline = { enabled = true },
          statusline = { enabled = true },
          select = { enabled = true },
          input = { enabled = true },
          notify = { enabled = true },  -- backend = 'builtin'
          indent = { enabled = true },  -- backend = 'builtin'
        })
<
                                                                      *g:neat*
vim.g.neat
    The same table (or a Lua function returning it). When set before
    startup, plugin/neat.lua calls |neat.setup()| with it.

                                                               *g:loaded_neat*
vim.g.loaded_neat
    Set to `true` before startup to turn the plugin off entirely.

Modules load on first use: the input window on the first |vim.ui.input()|,
the builtin notifier on the first |vim.notify()|, the builtin indent engine
with the first file buffer, the cmdline popup after |VimEnter|.

==============================================================================
3. COMMANDS                                                            *:Neat*

:Neat cmdline {enable|disable|toggle}                          *:Neat-cmdline*
    Turn the cmdline popup on or off.

:Neat statusline {enable|disable|toggle|refresh}            *:Neat-statusline*
    Take 'statusline' over or hand it back to what was there before.
    `refresh` drops every cache and redraws.

:Neat indent {on|off|toggle}                                    *:Neat-indent*
    Turn the builtin indent guides on or off.

:Neat notifications                                      *:Neat-notifications*
    Open the notification history of the active `notify` backend.

4. MODULES                                                      *neat-modules*

cmdline                                                         *neat-cmdline*
    Centred command-line popup on top of ui2 (`vim._core.ui2`). ui2 and
    'cmdheight' are left to your config; set `ui2.enable = true` to have
    neat turn ui2 on, and `ui2.cmdheight = 0` to have it set 'cmdheight'.
    The popup needs no cmdline row, so 'cmdheight' 0 with ui2's "msg"
    target suits it: >lua
        vim.o.cmdheight = 0
        require('vim._core.ui2').enable({ msg = { targets = 'msg' } })
<   Messages are routed by |ui-messages| kind
    (`messages.routes`): errors, warnings and short `:echo`/`print()`
    output become |vim.notify()| toasts (with neat's `notify` module),
    output longer than `messages.pager_lines` and `:!cmd` output open
    ui2's pager as a centred float, the rest stays with ui2. |:messages|
    and |g<| keep working. |confirm()| and `:s///c` prompts show in a
    float; `z=` and |inputlist()| lists stay with ui2's dialog. Options:
    `cmdline` (view, format), `messages` (`enabled`, `routes`,
    `pager_lines`), `confirm` (`style` = "center", "box", "toast" or
    "ui2"), `ui2` (`enable`, `cmdheight`, `disable_cmdline`, `pager`),
    `throttle`, `views`, `format`, `debug`. Defaults are in
    lua/neat/cmdline/config/init.lua. Highlight groups keep noice's names
    (`NoiceCmdlinePopup`, ...).

statusline                                                   *neat-statusline*
    Statusline built from sections `a`, `b`, `c`, `x`, `y`, `z`. Each takes
    component names (`mode`, `branch`, `diff`, `fileicon`, `filepath`,
    `filename`, `diagnostics`, `lsp`, `lsp_progress`, `location`,
    `progress`, `recording`, `searchcount`, `showcmd`) or functions
    `function(ctx) return string end`. `recording`, `searchcount` and
    `showcmd` (via 'showcmdloc', which neat sets to "statusline") show
    what the cmdline row did before 'cmdheight' 0.
    `lsp_progress` shows LSP `$/progress` (title, message, percentage)
    and is in section `y` by default. Other options: `palette`, `colors`,
    `icons`, `lsp_scope` ("all" or "buffer"), `diagnostics_update_in_insert`,
    `inactive_sections`, `extensions` (filetype -> sections). Defaults are
    in lua/neat/statusline/config.lua. The `Stl*` highlight groups are
    defaults, so a colorscheme can override them.

    `providers` picks where file icons and git status come from:
    `icons` = "devicons" (nvim-web-devicons) and `git` = "gitsigns" by
    default. Each also takes your own adapter (|neat-statusline-providers|)
    or false (no icons; branch from .git/HEAD and no diff).

select                                                           *neat-select*
    |vim.ui.select()| through a picker `backend`: "telescope" (a dropdown,
    the default), "builtin" (Neovim's own menu) or your own adapter
    (|neat-select-backend|). Calls are queued, so two pickers never open
    at once. When the backend is not available (telescope not installed),
    Neovim's menu is used. Options: `backend`, `trim_prompt`, `telescope`
    (picker opts; {} means the dropdown theme), `builtin`,
    `format_item_override` (kind -> format_item).

spell                                                             *neat-spell*
    |z=| lists spelling suggestions through |vim.ui.select()|, so they open
    in whatever picker implements it (neat's `select`, or another plugin).
    With Neovim's own |vim.ui.select()| that is the usual numbered list. A
    count (`3z=`) still picks directly, and the word is replaced in place
    without touching registers.

    `keymap` (default true) maps `z=` to `<Plug>(neat-spell-suggest)`,
    unless `z=` is already mapped. Set it to false and map the <Plug> key
    yourself to use another key: >lua
        vim.keymap.set('n', '<leader>z', '<Plug>(neat-spell-suggest)')
<

input                                                             *neat-input*
    |vim.ui.input()| in a floating window with history and completion.
    Options: `icon`, `icon_hl`, `icon_pos`, `prompt_pos`, `win`, `expand`.

notify                                                           *neat-notify*
    |vim.notify()| backend: `backend` = "builtin" (toasts), "native" (ui2),
    "nvim-notify" or your own adapter (|neat-notify-backend|). `builtin`
    and `nvim_notify` pass options to each backend. nvim-notify is
    required on the first message, not at setup. LSP progress is in the
    statusline (|neat-statusline|).

indent                                                           *neat-indent*
    Indent and scope guides: `backend` = "builtin" or "blink"
    (blink.indent). `builtin` and `blink` pass options to each backend.

    "builtin" is code adapted from snacks.nvim that ships inside neat, so
    its options keep snacks' names; snacks.nvim is not needed.

rename                                                           *neat-rename*
    `require('neat.rename').on_rename_file(from, to, rename?)` sends LSP
    `workspace/willRenameFiles` and `workspace/didRenameFiles`. Call it from
    a file explorer's rename event. Needs no setup.

5. ADAPTERS                                                    *neat-adapters*

neat never assumes a plugin is installed. Where a module uses another plugin
(a picker, a notifier, an icon set, a git integration) it goes through a
small adapter: a Lua table with a few functions. The adapters neat ships are
picked by name and required only when chosen; the defaults are telescope,
nvim-web-devicons and gitsigns. Pass a table of your own instead of a name
to use anything else. The types are in the module sources (LuaCATS), so
LuaLS completes and checks them.

Rules every adapter follows:
- Do not require the plugin at the top of the file or when the table is
  built. Require it inside the functions, on first use.
- Return quickly and never error when the plugin is missing: report it
  through `available()`/`load()` and let neat fall back.

select backend                                           *neat-select-backend*
    `neat.select.Backend` (lua/neat/select/init.lua):
    `available()`     true when the picker can be used now. Called on
                      every |vim.ui.select()|; may require the picker.
    `select(items, opts, on_choice, backend_opts)`
                      show the picker; call `on_choice(item, idx)` once,
                      or `on_choice()` when cancelled. `opts.prompt` and
                      `opts.format_item` are always set.
    Example with mini.pick: >lua
        select = {
          enabled = true,
          backend = {
            available = function()
              return pcall(require, 'mini.pick')
            end,
            select = function(items, opts, on_choice)
              require('mini.pick').ui_select(items, opts, on_choice)
            end,
          },
        }
<    For snacks.nvim, call `Snacks.picker.select(items, opts, on_choice)`.

notify backend                                           *neat-notify-backend*
    `neat.notify.Backend` (lua/neat/notify/init.lua):
    `notify(msg, level, opts)`  becomes |vim.notify()|.
    `toasts`          true when messages show outside the message area. The
                      cmdline module routes messages to |vim.notify()|
                      only when true, so they are not echoed back.
    `history()`       optional; opens `:Neat notifications`.
    `setup(opts)`     optional; called by |neat.setup()|. Keep it cheap.
    Example with mini.notify: >lua
        notify = {
          enabled = true,
          backend = {
            toasts = true,
            notify = function(msg, level, opts)
              local MiniNotify = require('mini.notify')
              if not _G.MiniNotify then MiniNotify.setup() end
              return MiniNotify.make_notify()(msg, level, opts)
            end,
            history = function() require('mini.notify').show_history() end,
          },
        }
<
statusline providers                               *neat-statusline-providers*
    The statusline is drawn under textlock, where a plugin manager's
    require hook may fail (E565), so providers split loading from reading.

    `neat.statusline.IconProvider`:
    `load()`          require the icon plugin, return whether it is there.
                      Called once, just after the first draw.
    `get(name, filetype)`  return icon and highlight group, or nil. Called
                      while drawing; must not load anything.

    `neat.statusline.GitProvider`:
    `status(buf)`     return `{ head?, added?, changed?, removed? }` or nil.
                      Without `head` the branch is read from .git/HEAD.
    `events`          optional autocmds after which statuses are stale,
                      e.g. `{ { event = 'User', pattern = 'MiniDiffUpdated' } }`.

    Example with mini.icons and mini.diff/mini.git: >lua
        statusline = {
          enabled = true,
          providers = {
            icons = {
              load = function()
                local ok, icons = pcall(require, 'mini.icons')
                if ok and not _G.MiniIcons then icons.setup() end
                return ok
              end,
              get = function(name) return MiniIcons.get('file', name) end,
            },
            git = {
              status = function(buf)
                local diff = vim.b[buf].minidiff_summary or {}
                local git = vim.b[buf].minigit_summary or {}
                return { head = git.head_name, added = diff.add,
                         changed = diff.change, removed = diff.delete }
              end,
              events = {
                { event = 'User',
                  pattern = { 'MiniDiffUpdated', 'MiniGitUpdated' } },
              },
            },
          },
        }
<

6. HEALTH                                                        *neat-health*

`:checkhealth neat` checks Neovim, unknown options, the adapters each enabled
module uses (nui.nvim, telescope, nvim-notify, blink.indent, gitsigns,
nvim-web-devicons, or your own), whether another plugin replaced |vim.notify()|,
|vim.ui.select()|, |vim.ui.input()| or 'statusline' after neat, and whether
each ui2 patch applied.
